Web Development Resources

Resources to support students who are learning the foundations of web development.

Introduction to Web Development

Web development involves creating and maintaining websites and web applications. Students can begin by learning the structure of web pages before progressing to styling, interactivity and responsive design.

The resources below introduce some of the main topics that students should understand when learning web development.

HTML

HTML is used to structure the content of a web page. Students can learn about headings, paragraphs, links, images, lists, tables, forms and semantic elements.

CSS

CSS is used to style web pages. It can control colours, typography, spacing, layouts, borders, backgrounds and responsive designs.

JavaScript

JavaScript can be used to add interactive behaviour and dynamic functionality to websites.

Responsive Web Design

Responsive design allows websites to adapt to different screen sizes such as desktop computers, tablets and mobile phones.

Website Accessibility

Accessibility involves designing websites so that they can be used by people with different abilities and ways of interacting with technology.

Web Development Practice

Practising by creating small web pages can help students understand how HTML and CSS work together.

Study Tips for Web Development

  1. Practise HTML structure regularly.
  2. Use CSS to experiment with layouts and typography.
  3. Test websites at different screen sizes.
  4. Use browser developer tools to inspect your code.
  5. Keep your files organised using clear folder names.
